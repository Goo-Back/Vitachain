# VitaChain VPS Deployment Scripts

This directory contains the complete set of scripts for provisioning and configuring the VitaChain VPS infrastructure.

## Overview

These scripts automate the complete VPS setup process as specified in story `1-1-vps-deployment-setup`. They follow the exact sequence outlined in the implementation steps and include comprehensive error handling and verification.

## Scripts

### 1. provision-vps.sh
**Purpose:** Initial VPS provisioning preparation  
**Usage:** `./provision-vps.sh`  
**Description:** 
- Generates SSH key pair for VPS access
- Provides step-by-step instructions for DigitalOcean droplet creation
- Creates SSH configuration template
- Shows public key for copying to DigitalOcean

### 2. setup-system.sh
**Purpose:** Basic system configuration  
**Usage:** `sudo ./setup-system.sh` (run as root on VPS)  
**Description:**
- Updates system packages
- Sets timezone to Africa/Casablanca
- Configures hostname
- Creates non-root user with sudo access
- Sets up SSH access for non-root user
- Pre-configures Docker sudo access

### 3. setup-firewall.sh
**Purpose:** UFW firewall configuration  
**Usage:** `sudo ./setup-firewall.sh` (run as root on VPS)  
**Description:**
- Installs and configures UFW firewall
- Sets default policies (deny incoming, allow outgoing)
- Allows essential ports (22, 80, 443)
- Enables firewall with safety checks
- Verifies firewall configuration

### 4. install-docker.sh
**Purpose:** Docker and Docker Compose installation  
**Usage:** `sudo ./install-docker.sh` (run as root on VPS)  
**Description:**
- Installs Docker Engine from official repositories
- Installs Docker Compose v2.24.5
- Configures Docker service to start on boot
- Adds non-root user to Docker group
- Tests Docker and Docker Compose functionality

### 5. security-harden.sh
**Purpose:** Security hardening measures  
**Usage:** `sudo ./security-harden.sh` (run as root on VPS)  
**Description:**
- Installs and configures Fail2Ban for SSH protection
- Enables automatic security updates
- Disables root SSH login
- Disables password authentication
- Creates security monitoring script
- Applies SSH security best practices

### 6. verify-setup.sh
**Purpose:** Complete setup verification  
**Usage:** `sudo ./verify-setup.sh` (run as root on VPS)  
**Description:**
- Verifies all 12 critical setup requirements
- Tests SSH access, firewall, Docker, and security configurations
- Provides detailed pass/fail report
- Generates success/failure summary
- Offers troubleshooting guidance

## Usage Sequence

Execute the scripts in this exact order:

1. **Local Machine:** `./provision-vps.sh`
   - Generate SSH keys and get droplet creation instructions
   - Create droplet in DigitalOcean console
   - Note the IP address

2. **VPS (as root):** `sudo ./setup-system.sh`
   - Configure basic system settings
   - Create non-root user

3. **VPS (as root):** `sudo ./setup-firewall.sh`
   - Configure security firewall

4. **VPS (as root):** `sudo ./install-docker.sh`
   - Install Docker and Docker Compose

5. **VPS (as root):** `sudo ./security-harden.sh`
   - Apply security hardening

6. **VPS (as root):** `sudo ./verify-setup.sh`
   - Verify complete setup

## Prerequisites

- DigitalOcean account with droplet creation permissions
- Local machine with SSH client
- Ubuntu 24.04 LTS droplet (2GB RAM minimum)
- SSH key pair (generated by provision-vps.sh)

## Configuration

All scripts use the following default configuration:

```bash
HOSTNAME="vitachain-vps"
TIMEZONE="Africa/Casablanca"
NON_ROOT_USER="vitachain"
SSH_KEY_NAME="vitachain_do"
DROPLET_SIZE="s-2vcpu-4gb"  # 2GB RAM, 1 CPU, 40GB SSD
DROPLET_REGION="ams3"  # Amsterdam
DOCKER_COMPOSE_VERSION="v2.24.5"
```

## Security Features

- SSH key-based authentication only
- Root SSH login disabled
- Password authentication disabled
- UFW firewall with only essential ports open
- Fail2Ban SSH protection (3 strikes, 1-hour ban)
- Automatic security updates
- Docker security best practices

## Troubleshooting

### Common Issues

1. **SSH Connection Issues**
   - Verify SSH key permissions: `chmod 600 ~/.ssh/vitachain_do`
   - Check firewall allows port 22
   - Verify droplet IP address

2. **Permission Denied Errors**
   - Ensure scripts are run with sudo: `sudo ./script.sh`
   - Verify user is in sudo group: `groups vitachain`

3. **Docker Permission Issues**
   - User must logout and login after being added to docker group
   - Verify group membership: `groups vitachain`

4. **Firewall Issues**
   - Check UFW status: `sudo ufw status verbose`
   - Reset firewall if needed: `sudo ufw --force reset`

### Log Locations

- SSH logs: `/var/log/auth.log`
- Docker logs: `journalctl -u docker`
- Fail2Ban logs: `/var/log/fail2ban.log`
- System logs: `journalctl`
